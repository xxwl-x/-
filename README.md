# 信息可视化案例仓库规则

## 入库流程（2026-11-20修订）
1. 每个案例先在编年型、层级型、编目型、字母表型、地理图形五大类中选定**唯一主分类**；不可多重主归属。
2. 再选择具体图形标签；一个案例可以包含多个标签，但要明确主标签与辅助标签。
3. 原图依据逐项拆分为可复核的基础数据集：每行一对象，每列一原子属性，每格仅一个值；数字与单位分列，原始数值与换算值分列。
4. 分析图形特性、制作方法、可复现制作流程。
5. 提炼视觉编码（数据字段→视觉通道）及视觉叙事（阅读路径、焦点、对比关系）。
6. 将案例分析 Markdown、结构化基础数据 CSV、字段字典、来源/局限说明共同入库；有条件时额外提供 XLSX。
7. 凡从图片估测所得的坐标、尺寸、配色和比例，应标注“估测”而非“原始数据”；缺失字段保留空值，禁止虚构。
8. 更新分类定义时优先保留可追溯来源，并让每个案例的标签与主分类保持一致。

## 五大类目录
- 01-编年型信息图形
- 02-层级型信息图形
- 03-编目型信息图形
- 04-字母表型信息图形
- 05-地理图形信息图形

## 案例目录规范
每个案例单独建立文件夹，至少包含：`分析报告.md`、`基础数据.csv`、`数据字典.csv`、`数据局限.md`。
